### Answers

#### 126. What is DHCP? [D | EL]
* **Definition:** Dynamic Host Configuration Protocol is a Layer 7 network management protocol used to automatically assign IP addresses, subnet masks, default gateways, DNS servers, and other network settings to endpoints.
* **Default Ports:** UDP port **67** (Server) and UDP port **68** (Client).

#### 127. Explain DHCP DORA. [D | EL]
1. **Discover (Broadcast):** The client broadcasts a request looking for available DHCP servers on the local segment.
2. **Offer (Unicast/Broadcast):** A DHCP server offers an available IP address, subnet mask, and lease duration.
3. **Request (Broadcast):** The client formally requests the offered IP address from that specific server.
4. **Acknowledge (Unicast/Broadcast):** The server confirms the lease reservation and sends final network parameters to the client.

#### 128. What is a DHCP scope? [D | EL]
* **Definition:** A contiguous range of IP addresses configured on a DHCP server for a specific subnet, along with associated parameters like gateway IPs, subnet masks, and DNS servers.

#### 129. What is a DHCP lease? [D | EL]
* **Definition:** The configurable amount of time a client is legally permitted to use an assigned IP address before it must renew the assignment with the DHCP server (renewals typically start halfway through the lease time at T1).

#### 130. What is a DHCP reservation? [D | EL]
* **Definition:** A configuration rule mapping a client device's fixed Layer 2 MAC address to a specific IP address within a scope, ensuring the endpoint always receives the exact same IP address dynamically.

#### 131. What is a DHCP exclusion? [D | EL]
* **Definition:** A specific IP address or range of IP addresses within a DHCP scope that the DHCP server is forbidden from handing out dynamically (typically reserved for static devices like switches, printers, or gateways).

#### 132. What is DHCP relay? [D | ML]
* **Definition:** A router feature (configured using `ip helper-address` on Cisco) that intercept local Layer 2 DHCP broadcast messages (`DISCOVER`) on a client subnet and forwards them as Layer 3 unicast packets to a centralized DHCP server on another subnet.

#### 133. How do you troubleshoot a client that cannot obtain an IP address? [T | EL]
1. **Physical Layer:** Check link status LEDs, network cables, or Wi-Fi association.
2. **Check Current IP:** Run `ipconfig /all` to see if the client has assigned itself an APIPA address (`169.254.x.x`).
3. **Force Renew:** Run `ipconfig /release` followed by `ipconfig /renew`.
4. **Network Verification:** Verify port VLAN assignment on the switch and ensure the DHCP scope is not out of available IP addresses.

#### 134. A whole VLAN is receiving APIPA addresses. What do you check? [S | EL]
1. **DHCP Scope Exhaustion:** Check if the IP pool for that VLAN has run out of available addresses.
2. **DHCP Relay Configuration:** Verify if the Layer 3 switch or gateway interface for that VLAN has a valid `ip helper-address` pointed to the DHCP server.
3. **Server Reachability:** Confirm the centralized DHCP server is online, operational, and reachable from that VLAN's gateway.
4. **VLAN Tagging/Trunking:** Ensure the VLAN is properly configured and allowed on trunk links between switches.

#### 135. DHCP works in VLAN 10 but not VLAN 20. How do you investigate? [S | ML]
1. **Compare Scope Configurations:** Check the DHCP server to verify an active, non-exhausted scope exists specifically for VLAN 20's subnet.
2. **Check IP Helper Address:** Ensure the Switched Virtual Interface (SVI) or sub-interface for VLAN 20 has the `ip helper-address` configured, while VLAN 10 already has it.
3. **Inspect Trunk & ACL Rules:** Confirm VLAN 20 is allowed across intermediate trunk links and that no access control lists (ACLs) are blocking UDP ports 67/68 between VLAN 20 and the DHCP server.

#### 136. What problems can be caused by a rogue DHCP server? [T | ML]
* **IP Conflicts & Outages:** Misconfigured wireless routers connected to the network can hand out invalid IP addresses, incorrect default gateways, or wrong DNS servers to legitimate clients.
* **Man-In-The-Middle (MITM) Attacks:** An attacker can run a malicious DHCP server to redirect client default gateways to themselves, intercepting sensitive network traffic.
* **Mitigation:** Enable **DHCP Snooping** on Layer 2 switches to drop unauthorized DHCP server responses on untrusted ports.

#### 137. Explain DHCP to a non-technical customer. [N | EL]
* **Analogy:** "Imagine checking into a hotel. Instead of picking any random room key yourself, you go to the front desk. The receptionist assigns you an available room number and hands you a keycard that works for the duration of your stay. DHCP acts as that automated front desk for your devices, assigning them valid network address passes so they can talk on the network without conflicts."
