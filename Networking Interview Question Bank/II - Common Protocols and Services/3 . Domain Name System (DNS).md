### Answers

#### 111. What is DNS? [D | EL]
* **Definition:** Domain Name System (DNS) is a Layer 7 network service that translates human-readable domain names (e.g., `google.com`) into computer-readable IP addresses (e.g., `142.250.190.46`).
* **Default Port:** Uses UDP/TCP port **53**.

#### 112. Explain the DNS resolution process. [D | EL]
1. **Local Check:** Client checks its local DNS cache and `hosts` file.
2. **Recursive Resolver:** If missing, client queries the Recursive DNS Resolver (e.g., ISP or `8.8.8.8`).
3. **Root Server:** Resolver asks a Root Server (`.`), which directs it to the TLD Server.
4. **TLD Server:** Resolver asks the Top-Level Domain server (`.com`), which points to the domain's Authoritative Server.
5. **Authoritative Server:** Provides the exact IP address back to the resolver, which caches it and returns it to the client.

#### 113. What is a DNS resolver? [D | EL]
* **Definition:** A server (usually provided by an ISP or enterprise network) that receives recursive DNS queries from client endpoints and carries out the lookup chain across root, TLD, and authoritative DNS servers to return the final IP address.

#### 114. What is an A record? [D | EL]
* **Definition:** Address Record—maps a domain or hostname directly to an **IPv4** address.
* *Note:* An **AAAA record** maps a hostname to an **IPv6** address.

#### 115. What is a CNAME record? [D | EL]
* **Definition:** Canonical Name record—an alias that maps one domain name to another domain name instead of directly to an IP address (e.g., mapping `www.example.com` to `example.com`).

#### 116. What is an MX record? [D | EL]
* **Definition:** Mail Exchanger record—specifies the email servers responsible for receiving incoming email messages on behalf of a domain.

#### 117. What is DNS caching? [D | EL]
* **Definition:** The temporary storage of previously resolved DNS records in local OS memory or resolver cache to speed up subsequent requests and reduce global network traffic.

#### 118. How do you troubleshoot a DNS failure? [T | EL]
1. **Test Direct Resolution:** Use `nslookup domain.com` or `dig domain.com` to check if a valid IP is returned.
2. **Compare Resolvers:** Query a public DNS server directly (`nslookup domain.com 8.8.8.8`) to bypass local network DNS.
3. **Verify Settings:** Run `ipconfig /all` to check the client's configured primary/secondary DNS servers.
4. **Flush Cache:** Run `ipconfig /flushdns` to clear local stale records.

#### 119. A user can ping 8.8.8.8 but cannot open google.com. What is likely wrong? [T | EL]
* **Diagnosis:** Layer 3 reachability is working properly, but **DNS resolution is failing**.
* **Fix:** Check local DNS server settings, verify if DNS ports (UDP 53) are blocked, or flush the local DNS resolver cache.

#### 120. Internal company names work, but public websites do not. What do you investigate? [S | EL]
1. **DNS Forwarders:** Check if the internal DNS server has valid **Forwarders** configured (e.g., `8.8.8.8` or ISP DNS) to resolve external domains.
2. **Root Hints:** Check if Root Hints are functional on the internal DNS server if forwarders are not used.
3. **Outbound Firewall Rules:** Ensure outbound UDP/TCP port 53 traffic from the internal DNS server to the Internet is not blocked by enterprise firewalls.

#### 121. DNS resolution intermittently fails for many users. How do you determine whether the issue is local, recursive, or authoritative? [S | ML]
* **Test Local:** Query the local corporate gateway/DNS (`nslookup domain <local-dns>`). If it drops requests or times out, the issue is local network/DNS infrastructure.
* **Test Recursive:** Query an external public recursive resolver (`nslookup domain 8.8.8.8`). If local fails but public works, the upstream ISP/recursive forwarder is failing.
* **Test Authoritative:** Query the domain's authoritative name server directly (`nslookup domain <ns1.domain.com>`). If authoritative fails, the host/zone configuration at the domain host is broken.

#### 122. Explain DNS using a phone-contact analogy. [N | EL]
* **Analogy:** "DNS is like the Contacts app on your smartphone. You know your friend by their name ('John'), but your phone can only place a call using their numeric telephone number. When you tap 'John', your phone looks up his name in your contacts list to find the actual phone number and make the call."

#### 123. What is split-horizon DNS? [D | ML]
* **Definition:** A DNS implementation where the same domain name resolves to different IP addresses depending on whether the query comes from inside the internal corporate network (resolves to internal private IP) or from the public Internet (resolves to public WAN IP).

#### 124. What is DNS TTL? [D | ML]
* **Definition:** Time To Live (TTL) is a value set by authoritative DNS servers telling local resolvers and client machines how many seconds they are allowed to store/cache a DNS record before discarding it and requesting a fresh copy.

#### 125. How can stale DNS caching cause a support issue? [T | ML]
* **Scenario:** When a web server or system migrates to a new IP address, client machines or recursive resolvers with cached old records (high TTL) keep sending traffic to the old/decommissioned IP address.
* **Result:** Users experience connection errors ("Page Cannot Be Displayed") until their local DNS cache is flushed (`ipconfig /flushdns`) or the TTL expires.
