### Answers

#### 101. What is HTTP? [D | EL]
* **Definition:** Hypertext Transfer Protocol is an unencrypted Layer 7 protocol used by web browsers and servers to request and transmit web content across the Internet.
* **Default Port:** Uses TCP port **80**.

#### 102. What is HTTPS? [D | EL]
* **Definition:** Hypertext Transfer Protocol Secure is the secure, encrypted version of HTTP that protects web traffic using Transport Layer Security (TLS).
* **Default Port:** Uses TCP port **443**.

#### 103. Why is HTTPS more secure than HTTP? [D | EL]
* **Encryption:** Encrypts web data in transit so eavesdroppers cannot read sensitive information like passwords or credit card numbers.
* **Data Integrity:** Prevents attackers from tampering with or altering data while it travels across the network.
* **Authentication:** Uses SSL/TLS digital certificates to verify the server's identity, ensuring clients are communicating with the genuine website.

#### 104. What is TLS? [D | EL]
* **Definition:** Transport Layer Security is a cryptographic protocol that provides end-to-end security, encryption, and data integrity over computer networks.
* **Relationship:** It is the modern, secure successor to the deprecated SSL (Secure Sockets Layer) protocol used to secure HTTPS, FTPS, and SMTP.

#### 105. What is a digital certificate? [D | EL]
* **Definition:** An electronic file issued by a trusted Certificate Authority (CA) that binds a public encryption key to an organization's domain name.
* **Purpose:** Validates website authenticity and enables encrypted HTTPS/TLS connections between web browsers and servers.

#### 106. A website opens using IP address but not its domain name. What do you check? [S | EL]
1. **Local DNS Resolver:** Check if the host can resolve domain names using `nslookup <domain>` or `dig <domain>`.
2. **DNS Server IP Configuration:** Check `ipconfig /all` to ensure valid DNS server addresses are configured.
3. **Hosts File:** Inspect the local `hosts` file (`C:\Windows\System32\drivers\etc\hosts`) for stale or bad mappings.
4. **DNS Cache:** Clear local DNS resolution cache using `ipconfig /flushdns`.

#### 107. A website is reachable but very slow. How do you troubleshoot it? [S | EL]
1. **Network Latency & Hops:** Run `traceroute` or `ping` to identify delay or packet loss along the path.
2. **DNS Resolution Time:** Test if name resolution is taking unusually long to complete.
3. **Browser Developer Tools:** Check the **Network tab** in Developer Tools (F12) to measure resource load times (TTFB, assets, API calls).
4. **Server Resources:** Investigate backend CPU, RAM, disk I/O, or database query bottlenecks on the web server.

#### 108. What would a browser error such as “connection timed out” indicate? [T | EL]
* **Meaning:** The browser sent an outbound request packet (TCP SYN), but received no response (SYN-ACK) from the server within the allowed time limit.
* **Common Causes:**
  1. The remote web server or service is completely offline.
  2. A local or network firewall/security group is blocking or silently dropping traffic on port 80/443.
  3. Routing failure preventing packets from reaching the destination IP.

#### 109. Explain HTTPS to a non-technical customer. [N | EL]
* **Analogy:** "HTTP is like sending a postcard through the mail—anyone along the postal route can read what is written on it. HTTPS is like putting that letter inside a locked steel box before sending it. Only you and the destination recipient have the key to open the box, so nobody along the way can peek at or tamper with what's inside."

#### 110. What is the difference between HTTP 4xx and 5xx errors? [D | ML]
* **HTTP 4xx (Client-Side Errors):** Indicates that the request sent by the client contains bad syntax or cannot be fulfilled by the server.
  * *Examples:* `404 Not Found`, `403 Forbidden`, `401 Unauthorized`.
* **HTTP 5xx (Server-Side Errors):** Indicates that the client's request was valid, but the server failed to process it due to an internal technical issue.
  * *Examples:* `500 Internal Server Error`, `502 Bad Gateway`, `503 Service Unavailable`.
